# Day 1: IndicVox AI - Giving Your Agent a Voice (#VoiceForBharat)

## Overview
Day 1 focused on building **IndicVox AI**, setting up LiveKit Agents with Murf Falcon TTS (`Anisha`, `en-IN`, Conversation Style), Deepgram Nova-3 STT, and Gemini LLM.

## Key Features Built
1. **LiveKit Integration**: Real-time WebRTC audio streaming.
2. **Murf Falcon Voice**: High-quality Indian accent voice synthesis with sub-300ms latency.
3. **Cyber-Bharat UI**: Futuristic glassmorphism web interface.
