Voice-first assistant for Bharat

Speak naturally. The agent listens, replies, and keeps the conversation going.

This build is tuned for a hands-free voice loop: press start once, talk normally, hear the reply out loud, and keep going. Text input stays available as a fallback when a browser blocks voice capture.

Input
Microphone with typed fallback
Output
Browser speech or Murf audio
Mode
Continuous turn-taking voice chat
Ready
Say something like hello, ask for help, or speak a short sentence. The assistant will answer aloud.
On browsers that support the Web Speech API, this page can keep listening after each reply. If microphone or speech support is blocked, use the text box and the assistant will still speak back.
